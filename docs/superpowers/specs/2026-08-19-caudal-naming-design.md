# Diseño: normalización del nombre Caudal

**Fecha:** 19-08-2026  
**Estado:** aprobado para ejecución  
**Alcance:** `workstream/authorized-red/**/*.md`

## Objetivo

Eliminar nombres ambiguos del proyecto, la red y sus productos sin atribuir prematuramente “Caudal” a una razón social todavía no constituida.

## Convención

| Concepto | Nombre que se usará |
|---|---|
| Proyecto y marca | **Caudal** |
| Red de pagos | **red de pagos Caudal** en la primera mención; **red Caudal** después |
| Gateway o conector | **conector de Caudal** |
| Persona jurídica futura | **sociedad operadora de Caudal** o **entidad solicitante** |
| Rol normativo genérico | **administradora de red**, **partícipe** o **entidad**, según la norma |

“Nuestra red”, “nuestro gateway”, “la empresa” y expresiones equivalentes se reemplazarán cuando nombren específicamente a Caudal. Se conservarán cuando describan un actor genérico o cuando “entidad solicitante” sea jurídicamente más preciso.

## Archivos

Se revisarán todos los Markdown de `workstream/authorized-red/`, incluidos README, resumen ejecutivo, plan de negocio, plan de ejecución, cartera comercial, documentos regulatorios y preparación técnica.

## Criterios de aceptación

1. Los títulos y primeras menciones identifican a Caudal.
2. Los diagramas no usan “nuestra red” ni “nuestro gateway”.
3. La futura razón social no se presume definida.
4. Las obligaciones normativas conservan el sujeto jurídico correcto.
5. La convención queda documentada en el README del frente.
6. No quedan denominaciones ambiguas salvo usos genéricos justificados.
