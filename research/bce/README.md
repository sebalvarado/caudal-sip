# Fuentes primarias del BCE

Copias verificables de los documentos públicos del Banco Central del Ecuador que sustentan este proyecto. Cada PDF conserva la fuente oficial; el archivo `.md` homónimo es una transcripción mecánica para búsqueda y lectura por agentes.

**Prelación**: ante cualquier diferencia de formato, tabla, firma o contenido, prevalece el PDF. El Markdown no es una publicación oficial ni una interpretación de la norma.

## Uso por agentes

1. Consultar primero el `.md` para localizar el artículo, sección o término pertinente.
2. Verificar la cita y las tablas en el PDF enlazado desde ese Markdown.
3. Citar resolución + artículo, o catálogo + sección. No inferir reglas de detalle que el Catálogo Técnico aún no haya publicado.
4. Si el BCE reemplaza un documento, descargar la nueva versión, regenerar su Markdown y actualizar el SHA-256 y la fecha de descarga.
